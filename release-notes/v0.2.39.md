## 1. 构建隐患：`bundle:client` 会静默删掉 `lib/types/`（最优先）

**根因**：`tsdown.config.ts` 的 libConfig `outDir:'lib', clean:true` —— tsdown 的 clean 是 glob 递归删 outDir 下**一切**，而 `lib/types/**` 是 `tsc --emitDeclarationOnly` 的产物、`lib/` 又被 `.gitignore` 忽略（**删了不可从版本库恢复**）。单跑 `bundle:client` 会永久删掉类型声明，且没有任何测试会红。

**修法**：`clean: ['lib/*.js', 'lib/*.js.map', 'lib/*.cjs']`（只清构建器自己的产物）。
**证据（探针实测）**：预置 `lib/stale-probe.js` + 记录 `lib/types/client/index.d.ts` 哈希 → 跑 `bundle:client` → 类型声明**存活且哈希未变**、陈旧产物**被清**、`index.js`/`client.js` 齐全。
**不选**「给 `bundle:client` 追加 `--emitDeclarationOnly`」：那只是让两条命令等价，`clean` 仍会先删一次。

## 2. 静默席判据（会议机制缺陷的机器门）

**缺陷**：专家节点**可以在不调用 `roundtable_speak` 的情况下结束回合** —— 产出只落在主持人的结算通知里，账本 0 条、网关摘要缺该席、**导出整席丢失，且全程不报错**。本场现场复发 3 个席次（`minimal` R1、`user` R2、`impl` R1+R2）。

**新增 `src/silence.ts`（纯函数）+ `test/silence.test.mjs`**：签名 `analyzeSilence(meeting, utterances, options) → { closedRounds, closedSeats, emptyRounds, silentSeats, lateReplies }`。
三条护栏（每条都有"关掉它违规必须出现"的变异用例，证明断言有牙）：
1. **排除在飞轮**（否则每轮误报约 30%）；
2. **`status === 'removed'` 席位不计入有效派单集**（历史确有一场 8 席全 removed）；
3. **迟到 ≠ 静默**（迟到只记录，不算失败）。
硬阈值：口径三（**空轮 = 0**）。测试 6 夹具 + 3 变异 + 1 阈值 = **10/10 通过**。

## 3. 单线制归口：`implicit` / `deliverable` 由 host 判定

`visibility.isDeliverable(mode, from, to)`（复用 `recipientPolicy`）+ 快照边字段 `implicit` / `deliverable`；客户端**3 处** `id.startsWith('synthetic:')` 全部改为读字段 —— 消除"同一事实两个判定者"（客户端原先自带一份投递策略副本）。

## 4. KB 变更判定：从「用户勾选」改为「文件系统事实」

- **host**：`roundtable/kb.list` 现按文件返回 `valid`（host 侧已算好的摘要有效性；`undefined` = 从未生成摘要，与"已变更"区分）。
- **client**：删掉 `kbContentChanged` 复选框、状态、那条 user-action 与 zh/en 文案键（漏勾 = 变更永远不通知主持人，属静默失效）；改为在文件行内显示「内容已变更」。

## 5. 面板 7 → 5（B 中度）

- 删 `files` 面板（零数据源空壳）；`tasks` 并入 `agents`（同一 nodes 数组重复渲染）。
- **长 role 展开的零新状态替代**：`.agentRole` 直接换行显示（2 行 CSS），彻底删掉 `expandedTask` 状态与 `task*` CSS 共 7 条规则。
- host `ROUNDTABLE_PANELS` 收缩为 5；客户端不再自带 id 清单（只留 `PANEL_LABELS`，值收紧为 `RoundTableKey`），id 由 `prefs.get` 的 `panels` 字段下发 —— 消除**三处副本**。
- 顺带删除 9 条死 locale 键与 `kbChangedRow`/`switchInput` 死类。
- **新增 `test/panel-ids.test.mjs`**：源码级断言「客户端映射覆盖 host 全部 id」「视图渲染的 id 都在 host 清单内」「渲染集合与 host 集合**一一对应**」（`satisfies` 抓不到这类漂移，只有读源码的正则测试能抓）。

## 6. 五组 UI 文案与护栏

| 项 | 落地 |
| --- | --- |
| 连线语义（三处同时说） | 右键菜单首行说明 + 画布左下角常驻图例 + 「已连接」toast 改写（`edgeScopeHint`/`edgeLegend`/`edgeConnected`） |
| 待人类决策横幅 | 加指路句「回聊天窗口的选项卡片里回答」；**刻意不加按钮**（回答决策的 RPC 不存在，加了就是假入口） |

| 删除会议防误删 | confirm 补「会删什么 + 想留档先导出」；`meeting.delete` 接受 `captainSessionId` 比对 |
| Token 口径 | 给数值加 `title`「按发言文本估算，不含系统提示词与工具开销」（不改共用标签，避免连带设置页） |

⚠ **`meeting.delete` 的比对不是鉴权**：RPC 路由拿不到调用者身份（`index.ts` 只传 endpoint/payload），payload 里的 sessionId 属**自证、可伪造**；实测该路由三种 header 全 200 命中。真正的身份校验缺口在宿主 `webServer`，**挂账**。
