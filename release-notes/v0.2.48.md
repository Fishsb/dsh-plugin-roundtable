# RoundTable v0.2.48

**空状态就地开局**：「还没有圆桌会议」那一屏不再只是一句提示 —— 它带上了**群聊窗口的同一个输入框**，说一句议题，主持人当场拉起专家队伍。

（v0.2.47 的群聊视图见 [v0.2.47.md](./v0.2.47.md)。）

---

## 1. 诉求与边界

用户原话分两句，后一句覆盖前一句：

1. 「默认显示窗口不要这个窗口，默认显示群聊窗口」
2. 「**不用取消这个窗口**，但是这个窗口加一个输入框，也就是群聊窗口的对话输入框」

所以定稿是：**窗口保留，往里加输入框，且这个输入框就是群聊窗口的那一个**。默认视图**不改**（仍是拓扑）—— 第二条明确撤回了第一条的"默认显示群聊"。

## 2. 一个组件，两处使用（而不是两份拷贝）

新增 `src/client/ChatComposer.tsx`：`ChatView`（群聊窗口）与空状态窗口**引用同一个组件**。

为什么不各写一份：这三处语义必须始终一致，两份拷贝会立刻漂移 ——
① Enter 发送 / Shift+Enter 换行（聊天窗口的肌肉记忆）；
② 发送中禁用（防重复提交）；
③ 空文本拦截（`trim()` 后为空不发，与"发送"按钮的禁用态一致）。

组件**不做 IO**：`onSend` 由调用方给，因为两处的发送目标不同（见下节）。

## 3. 没有会议时，这条消息去哪？

这是本版真正要回答的问题。群聊窗口有会议 → 落 `transcript.jsonl`；空状态**没有会议**，无处可落。

定案：**空状态输入框 = 开一场会议**，语义与 `/roundtable <议题>` 斜杠命令完全一致（`src/index.ts` 的处理器）：① 把该会话标记为讨论模式；② 用 steer 把议题作为一条插件来源的用户消息交给主持人，主持人据此出设置卡片、拉起专家队伍。

新增端点 `roundtable/steer`。三条刻意的选择：

| 选择 | 理由 |
|---|---|
| **复用 `steerCaptain`**（`members.ts`） | 那是本插件唯一的主持人投递入口，另写一条 steer 路径必然漂移 |
| **不复用 `runModeCommand`** | 那个函数按斜杠命令语法解析，输入 `off` 会**退模式而不转交**（见 `parseModeCommand`）。输入框里打的每个字都是**议题** —— 否则用户想讨论"off 这个关键字怎么处理"时，模式会被静默关掉 |
| **先置模式再 steer** | 模式段是 system prompt 的一部分，顺序反了就会出现"议题已转交但主持人不知道要按圆桌处理"的窗口 |

没有活 agent（页面刚刷新、会话已归档…）时**明确报错**，不假装已送达：
`session "<id>" has no live agent to steer`。

## 4. 顺带修掉的一处文案不一致

`emptyHint` 原本写「**回到聊天**，说一句…」—— 现在就在这一屏能输入了，那句话会把用户支走。改为「在下面的输入框里说一句议题…；也可以回到聊天说…」，两条路径都留着。

## 5. 工程注意（新引入的风险点）

- **hooks 顺序**：`if (meeting === undefined) return ...` 这个早退分支之后**不得再出现 hook**。无会议与有会议是同一个组件的两次渲染，hooks 数量不同会让 React 在切到下一个会议时直接抛错。`steerSending` / `startMeeting` 都声明在早退之前，并有守卫钉住。
- **CSS**：空状态的输入条复用 `ChatView.module.css`（同一个组件），外层 `.emptyComposer` 只负责给宽度并抹掉"页脚控件"观感（去顶边线、去背景）。

### 变异探针又抓到一条恒真守卫

变异 18（把 hook 挪到早退之后）第一轮报 **FAIL** —— 不是实现坏了，是我的断言**恒不命中**：

```js
after.match(/^\s*(useState|useEffect|...)\s*\(/gm)   // ← 永远匹配不到
```

本仓代码风格永远是**赋值式**（`const [x, setX] = useState(false)`），裸调用写法一次都不出现，所以这条断言永远绿。改为同时覆盖两种写法后，变异 18 正常转红。这正是本版反复用变异实测的意义：**"断言写了"与"断言有效"是两件事**。

## 7. 未做（明说）

- **默认视图仍是拓扑**：用户第二条明确撤回了"默认显示群聊"的要求。若仍希望默认群聊，是一行 `useState` 初值的改动，说一句即可。
- 空状态输入框**不显示历史会议**：`showAllMeetings: false`（互通关）时按会话过滤，新会话看不到别的会话的会议 —— 这是既有语义，本版不动。
